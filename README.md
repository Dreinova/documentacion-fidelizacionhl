# Documentación — Plan de Fidelización Harker Lloreda

Sitio de documentación (Docusaurus) con el manual de uso del Plan de Fidelización, la plataforma de puntos de Harker Lloreda. Contenido en `docs/`: módulo admin y portal de pacientes.

## Desarrollo local

```bash
npm install
npm run start
```

Abre `http://localhost:3000` con recarga en caliente.

## Build

```bash
npm run build
```

Genera el sitio estático en `build/`.
